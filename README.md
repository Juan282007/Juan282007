## 🚀 Featured Projects

### 🤟 One Language — Colombian Sign Language & Accessibility

A collaborative web, mobile, backend, database, and AI project focused on accessibility. Its computer-vision component recognizes **isolated signs from Colombian Sign Language (LSC)** using video or a camera and can display recognized signs as text and optional speech.

| Component | Stack | Repository |
| --- | --- | --- |
| AI recognition | Python, MediaPipe, TensorFlow / BiLSTM | [OneLanguage-AI](https://github.com/Juan282007/OneLanguage-AI) |
| Web & mobile | React, React Native, Expo | [Frontend](https://github.com/JohanAceroSalazar/OneLanguage_Frontend) |
| API & authentication | Java, Spring Boot, JWT | [Backend](https://github.com/JohanAceroSalazar/OneLanguage-Backend) |
| Database & migrations | PostgreSQL, Liquibase, Docker | [Database](https://github.com/JohanAceroSalazar/OneLanguage-Database) |

> This is a collaborative academic project. The recognition module currently classifies isolated signs; it does not translate continuous conversations.
